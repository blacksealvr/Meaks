MEKO GAMES VR — V3

IMPORTANT: Every HTML page in this V3 ZIP contains its CSS and page scripts directly inside the HTML. This means it will still look correct when you double-click index.html instead of hosting it first.

EDITING
-------
The easiest source files to edit are:
  js/config.js
  js/home.js
  js/games.js
  js/updates.js
  js/blog.js

For a hosted site, use the normal external JS/CSS files. The HTML files also contain embedded copies so local previews do not appear as plain unstyled HTML.

YOUTUBE
-------
A completely automatic newest-video lookup needs YouTube API/server-side access. For a simple no-API setup, you can embed your channel's uploads playlist. This playlist automatically updates whenever you upload. The uploads playlist ID is usually your channel ID with the first two letters UC replaced by UU. Example:
UC123... -> UU123...

You can put that playlist ID into the YouTube section when needed.
